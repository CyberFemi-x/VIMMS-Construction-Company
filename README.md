# VIMMS Construction Company Website

A modern responsive construction company website built with React and Vite.

## Overview

VIMMS Construction Company Website is a frontend web application designed to showcase construction services, company information, projects, and contact details with a modern industrial UI design.

The project focuses on:
- Responsive design
- Component-based React architecture
- Clean UI/UX
- Modular CSS structure
- Fast performance using Vite

---

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- JSX

---

## Features

- Responsive navigation bar
- Hero landing section
- Company statistics section
- About section
- Services section
- Project showcase
- Contact section
- Mobile-friendly layout
